# Myfin preview tap

The successful PR release publisher generates `aperture-preview.rb` here with a versioned download URL and SHA-256 checksum. It is intentionally absent until a real, complete installer release exists. See [installation and updates](../docs/RELEASES.md).

The cask was called `market-lens-preview` before the app was renamed to Aperture. `cask_renames.json` at the repository root points Homebrew from the old name to the new one.
